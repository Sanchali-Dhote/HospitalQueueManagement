# Hospital Queue Management System

This project is a simple web-based Hospital Queue Management System developed using JSP, Servlets, Java, JDBC, and MySQL.

The system helps manage patient appointments and hospital queues in an organized way. Patients can book appointments, select departments and doctors, and receive token numbers automatically. Hospital staff can manage the patient queue using the Call Next feature.

## Features

* Patient appointment booking
* Automatic token generation
* Department and doctor selection
* Queue display system
* Call Next patient functionality
* MySQL database connectivity
* Basic form validation

## Technologies Used

* Java
* JSP & Servlets
* JDBC
* MySQL
* Apache Tomcat
* HTML
* CSS
